# Protótipo de interface fornecido pelo grupo

Os arquivos HTML, CSS, JavaScript e imagens foram preservados do ZIP original para consulta e evolução visual.

**Atenção:** esta interface foi desenvolvida para uma API anterior, com rotas e endereço de servidor diferentes. Ela não está conectada automaticamente ao backend desta entrega. Para integrar, atualizar `static/js/auth.js` e os scripts de cada tela para usar as rotas `/api/...` documentadas no README principal e o token retornado em `POST /api/auth/login`.
